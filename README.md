# Jev Bookshelf

A visual semantic book-search experiment powered by TypeSafe AI's Jev.

The interface presents a moving wall of book spines. Natural-language searches pull matching books from the shelves, rotate them into cover view, and rank them by relevance.

## Status

Early planning and prototyping.

## Planned stack

- Next.js and TypeScript
- React and Motion
- TypeSafe AI JavaScript SDK
- Local candidate retrieval followed by Jev ranking
