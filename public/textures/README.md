# Bookcloth surface

Generated with the built-in image-generation tool for the decorative bookshelf spines. This is an original material study, not a photograph of a published edition.

- `bookcloth.png`: original generated source.
- `bookcloth.webp`: 768px optimized runtime texture, shared by every spine. Per-book background offsets and scale vary the surface without more requests.

## Generation prompt

Use case: photorealistic-natural. Asset type: grayscale bookbinding material texture for a website, to overlay on separately colored book spines. Generate a single square full-bleed macro photograph / high-resolution flatbed scan of old fine woven bookcloth, neutral mid-gray monochrome. Very fine irregular linen fibers, authentic mottled pigment, faint scuffs, tiny pale rubbed fiber flecks, delicate porous paper-like grain and subtle variation in density. Perfectly flat uniform diffuse lighting with NO directional light, NO vignette, NO broad shadow. Texture covers every pixel. Fine grain should be legible but not coarse burlap or a regular digital grid. Natural physical aged hardcover cloth, luxurious well-preserved library binding. No text, no lettering, no book shape, no edges, no objects, no border, no watermark. This will be used as a multiply/soft-light surface map at small scale.
